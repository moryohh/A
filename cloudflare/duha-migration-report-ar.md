# تقرير نقل منصة ضحى إلى Cloudflare — 2026-09-27

## النتيجة المختصرة

تم إنشاء **نواة تجريبية معزولة** للمحتوى التعليمي فقط:

- قاعدة D1 باسم `duha-content-index`.
- جدول `content_index` للفهارس ومعرفات المصدر.
- إدخال 5 سجلات تحقق من Supabase، مع نجاح القراءة والعينات.
- نشر Worker قراءة فقط واختباره عبر الرابط العام.
- لم يتم حذف أو تعديل بيانات Supabase الأصلية.
- لم يتم تغيير Supabase Auth أو Render أو رابط `VITE_COMMUNITY_API_URL`.

**لم يكتمل النقل الإنتاجي الكامل.** تم نشر Worker تجريبي للمحتوى المفهرس فقط، بينما المحتوى الكامل لم يُنقل إلى R2.

## ما بقي في Supabase وRender

- **Supabase Auth:** بقي كما هو.
- **المنشورات والتعليقات والإعجابات:** بقيت بالكامل على Render كما طلبت.
- **الرسائل والإشعارات:** بقيت في Supabase؛ لم تُنقل لأن نقلها يحتاج تحقق هوية وصلاحيات مستخدمين واختبار مستخدمين متعددين.
- **النقاط والمستويات:** بقيت في Supabase؛ لم تُنقل لتجنب التكرار أو فقدان الأرصدة.
- **نتائج الامتحانات:** بقيت في Supabase؛ لم تُنقل لتجنب فقدان النتائج أو كشف نتائج مستخدم آخر.
- **الألعاب المباشرة:** لم أنقلها؛ لا يوجد تنفيذ مثبت ومكتمل يمكن تحويله بأمان إلى Durable Objects في هذه المرحلة.
